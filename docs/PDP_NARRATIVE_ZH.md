# 详情页 = 叙事长图（非网页）

已上线 P01：https://pitchpro.p01.ccwu.cc

## 产品定义

**详情页交付物是一张竖版详情长图**（可对比两张选一），不是手机电商网页 / 模块 UI。

长图是 **淘宝式品牌生活方式详情长图**：把锁定产品嫁进品牌向往的生活方式——品牌调性、客群、消费场景、理念主张、成为什么样的人；图上用当地语言文案。

**不是** 冲突／痛点 → 解决方案戏剧叙事。

## 流程

1. **选设计** → 右侧锁定概念图  
2. 进入详情步：左侧「呈品 · 叙事师」**纯文字**描述长图上会排什么（开场情绪 → 品牌理念 → 产品融入 → 使用仪式 → 收束）  
3. 左侧聊改至满意 → 点 **「确认这版叙事」**  
4. 系统用锁定产品图 + 生活方式叙事（A 开场情绪＋理念 / B 使用仪式＋收束），Seedream **异步生成两张**竖版长图  
5. **右侧**对比两张 → 点选其一 → **「确认详情页」** → 产品提案 → 场景视频 → 出素材  

## 状态

| deliverable.status | 含义 |
|---|---|
| `narrative` | 左侧对齐长图故事；右侧等待 |
| `ready` | 已生成长图；右侧对比选图后可确认出素材 |

长图 URL 存在 `fileUrl`（当前选中）+ content 内 `<<<PDP_LONG_IMAGES>>>`（urls + selected）。

## 生图提示词

详见 [NARRATIVE_IMAGE_PROMPT_ENGINEER_ZH.md](./NARRATIVE_IMAGE_PROMPT_ENGINEER_ZH.md)：两张长图 = 开场情绪／品牌理念 vs 使用仪式／收束（都是品牌世界）；5 段式提示词 + 一致性锁定；对接视频工程师。

## 实现要点

- `confirmNarrative`：生成 2 张长图（i2i 参考锁定概念），status→`ready`
- `selectPdpLongImage`：右侧点选方案
- `confirmPdp`：须已 ready，再进出资材
- `PdpPanel`：无手机电商框；长图对比 + 放大

## 出素材

右栏同源素材包 Tab **「叙事长图」**（原「详情页」）展示已确认的生活方式叙事长图预览与打开链接；产品提案 PDF 会把长图编进带图画册。
