# 详情长图：分辨率 + 图上语言 + 放大

部署：https://pitchpro.p01.ccwu.cc（2026-10-28）

## 改动
1. **固定尺寸** `1080x3240`（1:3，短边 1080p+）。Seedream 5 flash 自定义像素上限约 4.62M，`1440x4320` 超限故不用。两方案同 size；失败再依次回退 `1440x2880` → `2K` 并打日志。
2. **`resolveOnImageLanguage(country)`**：非中国市场强制图上目标语种，并硬禁汉字；左聊叙事仍可为中文。
3. **Lightbox**：右侧/聊天放大改为可纵向滚动的全分辨率 TOS URL，宽度上限约 720px（不再卡 480px）。

## 复测
确认叙事 → 再生成两张长图 → 放大看清晰度与图上文字语言。
