# 产品提案应包含什么？（PitchPro）

对照 Flow A：**聊方案 → 选设计 → 叙事长图 → 产品提案 → 场景视频 → 出素材 → 跟进**。

## 画册结构（给品牌买家看，图文并茂）

1. **封面主张** + 锁定概念主视觉（`[[VISUAL:hero]]`）
2. **品牌世界** — 调性 · 人群 · 向往的生活方式 · 共创目标 · 市场/赛道 + 叙事长图（`[[VISUAL:long]]`）
3. **产品概念与视觉方向** — 锁定概念、方向、说明（外观示意 vs 工程待确认）
4. **为何契合该品牌** — SKU 如何进入品牌世界
5. **工厂交付要点** — 价格带 / MOQ / 大货交期 / 打样周期 / 产能 / 包装；缺失写 **「待共创确认」**（禁止空 TBD）
6. **下一步** — 打样 · 报价 · 跟进（开发信 / 场景视频 / 出素材）

企业资料库上传规格书/报价后可并入「工厂资料库引用」钩子（`factoryMaterialsNote`）。

## 聊方案要聊透

系统会提醒工厂补充：受众、品牌调性、向往生活、价格带、MOQ、交期、打样、产能、包装，以便提案够厚。BRIEF 可写 `priceBand` / `moq` / `leadTime` / `sampleTimeline` / `capacity` / `packaging` / `brandTone` / `lifestyleAspiration`，写入 `constraints` 供提案读取。

**硬门禁（P1）**：确认简报前 `priceBand` / `moq` / `leadTime` 必须齐备，或各项显式「本次暂无」。见 `ORDER_WINNING_P123_ZH.md`。

**企业资料（P2）**：上传规格书/报价后会并入「工厂资料库引用」。

**出素材 ZIP（P3）**：一点下载整包（PDF + 图 + 视频 + 开发信 + 清单）。

## 和场景视频的分工

- **产品提案**：B2B 说服册（含交付事实）
- **场景视频**：方案 + 设计图 + 叙事长图 + 品牌调性 → ≤15s 生活方式介绍；**不依赖提案脚本**
