# 拿订单 · 第三批（长图 QA / 薄提案提示 / 检查清单）

> Asia/Shanghai · Flow A 补齐体验

## 1 — 叙事长图质量勾选

- **何时**：叙事长图 `ready`，点「确认叙事长图，进入产品提案」之前
- **三项**（须全部勾选，否则按钮禁用 + 中文拦截）：
  - 产品外观 OK
  - 品牌调性 OK
  - 图上语种 OK
- 切换项目 / 锁定设计会重置勾选

## 2 — 旧薄 PDF / Who·Why·How 提示

- **何时**：产品提案右栏加载到提案 deliverable
- **判定**：`isLegacyThinProposalOutline`（缺「工厂交付」或仍是旧 How 模板）
- **UI**：琥珀色横幅「大纲已加厚，请改大纲后重新生成 PDF」+ 引导点「不满意？改大纲后重新生成」

## 3 — 聊方案「拿订单检查清单」

- 右栏清单：品牌调性、目标人群、向往生活方式、价格带/MOQ/交期（硬）、包装/包材
- 已从 BRIEF/constraints 提炼的项标「已从对话提炼」；软项可勾「本项暂先确认」
- 硬门禁未齐时琥珀色提醒（与确认简报硬拦一致）
- 系统提示词同步提醒顾问按清单追问

## 验收

1. 长图未勾全三项时无法确认进提案  
2. 旧 Who/Why/How 提案内容出现加厚横幅  
3. 聊方案右栏见「拿订单检查清单」且随对话字段更新状态
